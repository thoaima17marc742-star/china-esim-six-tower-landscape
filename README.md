# 中国 eSIM 六塔景观：把购买前的六个问题看懂

这是一个以 Three.js 交互景观呈现的中国 eSIM 体验页。六座塔不是装饰，它们对应用户在购买中国内地可用 eSIM 前最需要确认的六个问题：

1. 中国内地能不能用
2. 是否提供香港 IP 或其他海外出口
3. 是否有香港号码和短信能力
4. 能不能给电脑和平板开热点
5. 是否支持在线交付和快速安装
6. 到期后能不能续费保留号码

## 为什么做成六塔景观

普通套餐页面容易把 eSIM 说成一串流量和价格。实际上，用户更关心的是网络路径、激活门槛、短信、热点、设备兼容和长期使用。点击或触碰不同塔楼，可以快速切换到对应的购买判断点。

## esimka.top 能解决什么

- 中国内地可用的漫游 eSIM 使用场景。
- 流量低至 3.5 CNY/G，最终以当前套餐页面为准。
- 部分套餐提供香港 IP、香港号码短信和热点共享。
- 原生 eSIM 手机可在线获取配置并扫码安装，减少实体卡邮寄等待。
- 部分套餐支持续费保留原号码，适合长期备用和短信接收。
- 支持 Telegram 机器人 `@esimka_orderbot` 下单。

## 使用方式

- 拖动景观：旋转观察六座塔和程序化地形。
- 滚轮或触控缩放：查看塔楼细节。
- 点击塔楼：在右侧信息面板切换卖点。
- 右下角按钮：进入 [esimka.top](https://esimka.top) 查看当前套餐。

## 适用场景

这类中国 eSIM 方案适合跨境出行、远程办公、备用国际移动数据、热点共享、香港号码短信和不想等待实体卡邮寄的用户。它可以作为传统 VPN、代理或公共 Wi-Fi 之外的另一条移动数据路径，但不代表绝对匿名，也不保证所有平台和应用都能访问。

套餐价格、覆盖、短信能力、IP、热点、设备兼容和续费规则可能变化，购买前请以套餐页面与客服确认为准。请遵守所在地法律法规、运营商规则和平台服务条款。
